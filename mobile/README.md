# LeadFlow AI — Mobile App (Flutter)

This folder has the real app source code (`lib/`, `pubspec.yaml`). It does
**not** yet have the `android/` and `ios/` platform folders — those are
auto-generated by the Flutter SDK itself, not hand-written, so they're
created in one command once you have Flutter installed.

## One-time setup (on a computer with Flutter SDK installed)

1. Open a terminal in this `mobile` folder
2. Run: `flutter create .`
   (this generates `android/`, `ios/`, `web/` folders around the existing
   `lib/` and `pubspec.yaml` — it will NOT overwrite your code)
3. Run: `flutter pub get`
4. Run: `dart run flutter_launcher_icons` then `dart run flutter_native_splash:create`
   (generates the real app icon + loading screen from `assets/icon/app_icon.png`
   and `assets/splash/splash_logo.png` — one-time, only needs re-running if
   you change those images)
5. Make sure the backend is running (see `../backend/README.md`)
6. Run: `flutter run` — pick your connected phone/emulator when prompted

## Screens included so far
- **Leads List** — search, filter by pipeline stage, pull to refresh
- **Add Lead** — simple form
- **Lead Detail** — stage changer, AI Insight (Claude), free WhatsApp send
  button, full communication history

## Note on the backend address
`lib/services/api_service.dart` points at `http://localhost:3000` for
local testing. Once the backend is deployed somewhere real, update
`baseUrl` in that one file.
